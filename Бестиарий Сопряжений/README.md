# Исчадия Сопряжений

Мастерский бестиарий D&D 2024 для шести хорошо экипированных персонажей 7-го уровня. Авторские ПО предварительные; игрового плейтеста не было.

- [Готовый PDF](<../output/pdf/Исчадия Сопряжений - бестиарий мастера.pdf>): 12 страниц A4, таблица встреч, общая памятка и отдельная страница каждого из десяти существ. Ссылки в таблице, закладки и ссылка в нижнем колонтитуле обеспечивают навигацию.
- `bestiary.json`: редактируемый исходник всех статблоков, механик окружения и рекомендуемых встреч. Элементы `sections` описывают способности, `gm` - окружение и тактику.
- `build_pdf.py`: воспроизводимая сборка PDF из исходника.
- `Источники/Книга охотников Этны.txt`: исходное описание существ, предоставленное мастером. Новые игровые механики не дописываются в канонический текст.

## Сборка

Требуются Python 3.10+, `reportlab` и шрифты с кириллицей. На Windows автоматически используются Arial и Georgia; на Linux - DejaVu Sans и DejaVu Serif.

```sh
python -m pip install reportlab
python build_pdf.py
```

Для другой папки шрифтов укажи `--font-dir`, для другого назначения - `--output`. По умолчанию результат записывается в `output/pdf/` репозитория. Шрифты встраиваются; страницы не зависят от наличия этих шрифтов у читателя.

## Содержание и границы

Сохранены статблоки, составы встреч и контрмеры из согласованной редакции чата от 23 октября 2026 года; текст уплотнён для одностраничного размещения. Для Перекошенного явно уточнено окончание вызванных нулём хитов ограничений после регенерации. Теневик остаётся необязательной интерпретацией слухов.

В таблице опыт Разрыва обозначает награду за закрытие источника, а не ПО монстра. Особые цепи, огонь, руны, якоря и вода - авторские свойства конкретных существ и встреч, а не общие правила D&D.

Правила-основа: [построение встреч](https://www.dndbeyond.com/sources/dnd/br-2024/dms-toolbox#CombatEncounterDifficulty), [глоссарий](https://www.dndbeyond.com/sources/dnd/br-2024/rules-glossary/), [статблоки](https://www.dndbeyond.com/sources/dnd/br-2024/creature-stat-blocks/).
